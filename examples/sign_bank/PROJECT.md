# 告示牌账户银行 v3

Minecraft Java Edition 26.3 / pack format 121.0。32 个独立账号，账号与密码分别存放在机房的两块告示牌；余额、尺寸、就绪状态保存在对应槽位的 marker 上。所有游戏逻辑用 MCL 结构化语法实现，严格模式为 0 条底层语句。

## 构建与安装

```powershell
cargo build --bin mclang
target/debug/mclang.exe check examples/sign_bank --deny-raw
target/debug/mclang.exe build examples/sign_bank -o build/sign_bank --deny-raw
```

将生成的整个 `build/sign_bank` 放入世界的 `datapacks`，然后执行 `/reload`。大厅位置为 `0.5 64 5.5`，面向北方（yaw=180）。超平坦地表高度不作依赖：大厅地板固定在 y=63。

新世界自动初始化；旧测试版本不迁移。旧世界更新后执行：

```mcfunction
/function sign_bank:reset
```

**reset 会清空本数据包的测试账号、余额和指定仓库区域内的物品/方块。** 普通 `/reload` 只注销会话、清理展示与未完成注册，不重建正式账号和房间。初始化等待所有目标区块加载完成后再放置方块。

## 操作

1. 首屏点击独立的登录或注册命令牌。
2. 中间输入牌的第一行填写账号，提交后才进入独立密码页。
3. 注册费 1 绿宝石；账号和密码写入后回读验证，通过才完成注册。
4. 仓库门厅中四块命令牌分别存入全部绿宝石、取出 1 枚、升级、安全退出。
5. 上方 text_display 显示槽位编号、余额、仓库尺寸与升级费用，满级显示已达上限。

输入按文本组件复制，不解析成数字。已验证前导零、英文、中文、字母数字混合、引号与反斜杠；`123` 和 `00123` 是不同账号。大小写与字符内容需要一致。

## 空间与数据

- 大厅/屏障机房：x=-10..10，y=63..82，z=-12..12。
- 槽位 i 的房间原点：x=100+16×(i-1)，y=63，z=0。阵列终点 x=607；各房间外壳 12×8×14。
- 可用仓储区：相对 x=1..n，z=3..n+2，n=3..10；另有固定 3×2 控制门厅，不计入仓储尺寸。
- 基岩墙/地板/顶板给出实际边界；雕纹石砖地板标识可用仓储区，y=69 的 light 方块提供 15 级照明。
- 升级仅开放新增两条边，不重填已有区域；费用等于新边长，3→10 共需 49 绿宝石。
- 常加载共 36 个区块（大厅 4 + 房间 32），只在主世界操作固定设施。
- 机房账号牌：x=-4+(i-1)%8，y=66+3×floor((i-1)/8)，z=-7；密码牌位于同列 y+1。
- scratch 的 x=5/6/7/8 分别为输入、比较、空白、预留账号，y=66，z=-7；不作为正式记录。
- marker 的固定整数槽位连接账号、密码、余额和房间，绝不根据用户名转数字或使用“最近 marker”匹配。
- 重复账号、重复 marker、无效页面、已在线账号和非独占仓库都拒绝操作。异常清理不能删除存在重复 marker 的正式凭据。
- text_display 带专属 `sb_display` 标签，更新前删除本槽位旧展示；退出、断线、重载、重建都清理，不影响其他实体。

2026-09-27：368 项断言通过，1 个 GameTest 场景通过。测试创建模拟玩家并调用告示牌原版点击入口，实际执行生成的 mcfunction。覆盖：

- 重复账号、重复槽位、其他账户密码的拒绝；清理不误删正式凭据。

- 每级 3×3→10×10 的基岩边界与 light 顶层；带 7 枚钻石的箱子内容保持不变。

## 语言支持结论

已实际覆盖模块导入/上下文校验、score 参数与返回值、短路条件、unroll 坐标展开、结构化 execute/store、NBT 复制、clone/blocks 比较、实体查询、召唤与移除、计分文本、fill 筛选、跨维度和 schedule。

全部 7 个模块经 CLI 翻译为中文后再次严格编译，684 个产物文件与英文版本逐字节一致。最终函数引用无缺失，所有 `if blocks` 均显式包含比较模式。

发现的边界：

- MCL 尚未检查告示牌 NBT 字段对应的完整 codec：`front_text.color` 必须是染料色（如 cyan），内层文本 `color` 是聊天色（如 aqua）。此前错误把两者混用，Minecraft 日志会报错；示例已修正。
- 普通参数是 score，不可用来保存账号字符串；本例通过 NBT 原样复制。
- `~(编译期表达式)` 尚不支持，本例用 `unroll for` 计算绝对坐标。没有引入运行期字符串宏或原生命令逃生口。
- “旧版只有数字账号有效”的具体原因尚未由旧世界状态复现；不能把之前关于 clone 改变 NBT 的猜测当成确定根因。新方案的文字账号已在真实引擎中验证。

文件职责：`main.mcl` 管生命周期，`ui.mcl` 管菜单，`auth.mcl` 管认证流程，`accounts.mcl` 管双牌存储，`rooms.mcl` 管几何与独占检查，`bank.mcl` 管收支，`displays.mcl` 管展示清理。
