# 告示牌银行执行计划

- [x] 采用固定物理资源池：32 个账户槽位、32 间互相隔离的永久仓库，避免运行期原生命令和动态坐标注入。
- [x] 在 `(0, 64, 5)` 附近自动建立大厅、登录墙与屏障机房；在 `x=100..545` 建立仓库阵列。
- [x] 登录墙提供紧凑的三层告示牌首屏：`y=67` 状态屏、`y=66` 中央输入区、`y=65` 两块独立命令木牌。
- [x] 首屏未选择功能时中央牌锁定，下方左右命令牌分别只执行“登录账户”和“注册账户”；每块牌只保留一个点击事件。
- [x] 采用两阶段输入：先在第 1 行单独提交账号；账号存在或可注册时擦除输入牌，再在第 1 行单独提交密码。
- [x] 登录账号、登录密码、注册账号、注册密码分别是独立告示牌页面，每个子页面都有“提交当前输入 / 返回首屏”。
- [x] 把输入规范化到机房临时牌，并用 `execute if blocks` 对比受保护记录牌；另设账号索引牌阻止同名注册。
- [x] 注册第二阶段使用 `slot_used = -1` 临时保留槽位；取消、离开登录区、第二人进入或断线都会释放预留。
- [x] 注册费为 1 枚绿宝石；槽位、凭据、银行余额、仓库边长和物理方块随世界存档持久化。
- [x] 每个账户初始获得独立 3×3 仓储区和控制前室，可放置方块与箱子。
- [x] 房内命令牌支持“存入全部绿宝石、取出 1 枚、升级、退出”。升级费用等于新边长，逐圈扩到 10×10，旧区域绝不重填。
- [x] 对照 26.3 `SignBlockEntity`：所有命令牌同时写入 `is_waxed = true` 与 `allow_op_features = true`，否则只会显示“点击操作已被禁用”。
- [x] 每块命令牌只保留一个 `run_command`；房内四个动作拆成四块独立木牌，避免原版遍历四行并执行全部点击事件。
- [x] 命令牌直接调用导出的玩家函数，不再经过 `/trigger` 的启用、锁定和下一刻轮询；旧 trigger 入口只保留作手工诊断。
- [x] 四个认证页面使用四个页面专属提交函数，不再依赖 `auth_mode` 二次分发；每次提交先播放声音并显示 actionbar 状态。
- [x] 同一账户只允许一个在线会话；登录区出现第二名玩家时拒绝操作；仓库出现第二人时把房内所有玩家强制登出。
- [x] 玩家断线、离开所属仓库或进入错误仓库时注销会话并送回大厅。
- [x] 每秒修复大厅按钮牌与已启用仓库的控制牌，凭据记录牌和玩家仓储内容不参与修复。
- [x] 使用 `--deny-raw` 检查并构建，确认项目含 0 条底层语句。
- [x] 槽位表改用编译期循环 `unroll for`：索引是编译期常量、坐标由索引算出，展开后仍是 O(32) 条静态命令；运行期索引只保留一条 `if index == slot` 守卫。小数坐标（`enter_account` 落点）必须写字面量，保留显式展开。
- [x] 重写后核对产物：全包 838 条世界操作（`fill`/`clone`/`setblock`/`data modify`/`tp`）逐条一致，仅 `expand_room` 由 224 行合并条件改为 32 个槽位分派。
- [x] 收敛每刻开销：仓库审计加并集查询守卫、预留清理改为每秒执行、一次性告示牌清理移出热路径；空载每刻约 497 → 17 条命令。`enter_account` 落点改用整数格 + 0.5 相对偏移表达，32 个落点与朝向逐条一致。
- [x] 排查认证不推进：`execute if blocks` 之前省略了比较模式，26.3 会判为不完整命令，账号索引与凭据比较恒为假（登录永远“账号不存在”，同名检查失效）；编译器现在显式生成 `all`/`masked`，并在 `tests/command_outputs.rs` 加了回归断言。
- [x] 账号/注册页失败时不再擦除输入牌（原来失败也擦，下一次点击只会得到“账号不能为空”），只有进入下一页才清空。

## 验收顺序

1. 在全新超平坦世界安装数据包并执行 `/reload`，确认大厅、屏障机房和 32 个密封仓库自动生成。
2. 首屏中央牌不可编辑；点击下方独立的“注册账户”命令木牌后应切换到注册账号页，中央牌此时才可编辑。
3. 只在输入牌第 1 行填写注册账号并提交；系统确认可用、擦除输入并切换到注册密码页后，再单独填写密码。没有绿宝石时注册失败，有绿宝石时扣除 1 枚并进入 3×3 仓库。
4. 登出后从首屏选择登录并提交账号；不存在的账号不能进入密码页。存在的账号会进入独立密码页，错误密码返回账号页，正确密码回到原仓库。
5. 任一子页面点击“返回首屏”，确认输入牌重新锁定且临时注册槽位被释放。
6. 点击任一命令牌，确认不再出现“点击操作已被禁用”，并且每次只执行该木牌对应的一个动作。
7. 存入至少 49 枚绿宝石，连续升级到 10×10；每次只打开新的一圈，旧箱子不被清除。
8. 第二名玩家进入登录区后尝试登录，操作应被拒绝并警告。
9. 两名玩家同时出现在同一仓库，双方都应立即返回大厅且会话归零。
10. 登录后退出游戏再进入，旧会话应失效，必须重新输入凭据。
11. 两个不同账户分别存款、建造和升级，确认余额、尺寸与仓储内容互不串号。
