# 怪物积分商店

面向 Minecraft Java Edition 26.3 的 Mclang 示例数据包。`main.mcl` 负责市场与购买，`kills.mcl` 负责悬赏，`events.mcl` 负责玩家事件，`dialogs.mcl` 负责原生商店界面。生成后的 `build/monster_market` 可以直接复制进世界的 `datapacks` 目录。

```powershell
cargo run --bin mclang -- build examples/monster_market -o build/monster_market --deny-raw
```

进入世界后执行 `/reload`。玩家输入 `/trigger monster_market_shop_request set 9`，或点击首次进入时的聊天按钮打开原生对话框商店。界面提供市场规则和六种商品；进入详情页可查看物品图标、附魔和价格区间，再点击购买或返回。触发器会在下一游戏刻重新启用，所有扣款和发货都以发起请求的玩家为目标。

商店包含铁剑、盾牌、弓、锋利 II / 耐久 II 铁剑、力量 III / 耐久 II 弓和金苹果。各玩家拥有独立积分；每 100 **当前积分**增加 2 点最大生命值，上限增加 20 点。消费后生命值上限会随余额降低。属性由 `monster_market:points_health` 修饰器提供，不修改玩家原本的最大生命值基值。

动态成交价由四部分组成：基础价、商品独立需求、全局风险压力、军械或食物分类压力。每次成功购买使对应需求增加 2；每 1200 游戏刻，需求与三类压力各向正常值回落 1。每 6000 游戏刻有概率发生商队抵达、军械补货、金苹果丰收、怪物潮、军械商队遇袭或炼金原料短缺。所有状态随世界保存。

进度系统还监听十类玩家行为。村庄英雄、治愈村民、村民交易、每日睡眠和满级信标属于正面事件；阵亡、食用金苹果、触发不死图腾和获得袭击之兆属于负面事件；附魔物品同时奖励积分并提高军械原料压力。远古守卫者、Warden、凋灵和末影龙的击杀也会改变市场，其中 Warden 带来深暗遗物供应，凋灵造成战后需求，末影龙触发全服繁荣。

原生对话框资源是静态的，因此详情页显示价格范围；“市场规则与事件”页面提供“刷新实时价格”按钮，可把六种商品的当前报价显示到聊天并自动返回商店。结算使用点击购买时的实时价格，并在聊天中显示实际成交价。其他玩家的购买和事件可能在打开详情页之后改变成交价。

可用两名玩家做联机验收：

1. 分别击杀僵尸、精英怪和 Warden，确认得到 20、100 和 750 分；连续击杀同一档生物仍能重复奖励。全部 45 个 `MobCategory.MONSTER` 注册实体都应属于且只属于一个悬赏档。
2. 给一名玩家累积到 100 分，确认只增加该玩家的最大生命值；购买后余额低于 100 时，确认额外生命值撤销。
3. 两人打开原生对话框商店，确认市场规则、六个商品按钮和详情物品图标都可见；点击返回能回到列表。
4. 先让一人购买铁剑，再让另一人购买铁剑，确认第二笔交易受到需求上涨影响；购买后聊天显示实际成交价。
5. 让余额不足的玩家购买，确认显示“积分不足”、不发物品、需求价格也不变；确认点击其他商品不会错误扣款。
6. 触发村庄英雄、阵亡、金苹果消耗和不死图腾事件，确认正负事件只修改触发玩家的积分，但市场影响对全服共享。
7. 等待 1200 游戏刻后再购买，确认价格向正常值回落；重新执行 `/reload`，确认积分、需求和市场压力继续保留。

此数据包会在侧边栏显示积分。其他数据包若也使用侧边栏，最后设置显示槽的数据包会占用该位置。
